# Apache DataFusion Python 55.0.0 Changelog

This release consists of 35 commits from 15 contributors. See credits at the end of this changelog for more information.

**Breaking changes:**

- Add FFI query planner support [#1677](https://github.com/apache/datafusion-python/pull/1677) (timsaucer)
- Make extension codecs composable [#1678](https://github.com/apache/datafusion-python/pull/1678) (timsaucer)
- Report physical partitioning and resolve two panics escaping as PanicException [#1720](https://github.com/apache/datafusion-python/pull/1720) (timsaucer)
- chore: harden the extension API before it ships [#1759](https://github.com/apache/datafusion-python/pull/1759) (timsaucer)
- feat: close upstream coverage gaps for DataFusion 55.1.0 [#1763](https://github.com/apache/datafusion-python/pull/1763) (timsaucer)
- fix: Make default sort order nulls last [#1766](https://github.com/apache/datafusion-python/pull/1766) (nuno-faria)

**Fixed bugs:**

- fix: clone parquet-testing into `parquet` in verify-release-candidate.sh [#1617](https://github.com/apache/datafusion-python/pull/1617) (adriangb)
- fix: no panic on empty partition in register_record_batches [#1627](https://github.com/apache/datafusion-python/pull/1627) (fangchenli)
- fix: tighten scalar UDF return type hints [#1642](https://github.com/apache/datafusion-python/pull/1642) (BharatDeva)
- fix: remove todo from indexed field key [#1667](https://github.com/apache/datafusion-python/pull/1667) (BharatDeva)
- fix: forward write_options when write_parquet receives ParquetWriterOptions [#1761](https://github.com/apache/datafusion-python/pull/1761) (Rodrigo-Palma)

**Documentation updates:**

- docs: fix bootstrap instructions in contributor guide [#1618](https://github.com/apache/datafusion-python/pull/1618) (onestn)
- docs: explain S3 object-store configuration for SQL [#1716](https://github.com/apache/datafusion-python/pull/1716) (emecii)
