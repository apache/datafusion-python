# Contributing

Contributions are welcome, including issue reports, documentation, code, and
reviews. Before starting a substantial change, search the issue tracker and use
an issue to discuss its scope and expected behavior. Link the related issue in
your pull request and complete the
[pull request template](.github/pull_request_template.md).

The [README](README.md) documents the development environment, build and test
commands, and optional pre-commit hooks. The
[project contributor guide](docs/source/contributor-guide/index.md) has
additional guidance for contributors, including PyO3 and FFI-specific practices.
